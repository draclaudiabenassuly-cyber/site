# Seeds do CMS

`cms-source-seed.sql` contém os textos, imagens, agenda e notícias padrão que
estão no código-fonte atual.

Ele é um ponto de partida seguro para o novo banco. Para levar as alterações
mais recentes feitas pelo painel, baixe o backup JSON real pelo CMS e peça ao
Codex para convertê-lo/importá-lo antes de publicar a versão da Vercel.
